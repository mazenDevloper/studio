# DriveCast Sovereign Hub v3100.0 🚀
### نظام التشغيل المركزي المتكامل للسيارات - النسخة السيادية

مشروع **DriveCast** هو نظام واجهة مستخدم (UI/UX) متطور مصمم خصيصاً لبيئة السيارة، يعتمد على بنية **Next.js 15** ويجمع بين الترفيه، الإنتاجية، والروحانية في منصة واحدة موحدة تدعم التحكم عبر الريموت كنترول (الجويستيك)، الأوامر الصوتية، واللمس.

---

## 🛠 الترسانة التقنية (Tech Stack)
- **Framework**: Next.js 15 (App Router) مع Turbopack.
- **UI & Styling**: Tailwind CSS, Shadcn/UI, Radix UI.
- **State Management**: Zustand مع Persistence (التخزين المحلي).
- **Generative AI**: Google Genkit مع Gemini 2.5 Flash للتحليلات الرياضية والاقتراحات.
- **Backend & DB**: Firebase (Auth & Firestore) + JSONBin للمزامنة السحابية الفورية.
- **Graphics**: Three.js (لعرض مجسم السيارة 3D)، SVG Animations للساعات السيادية.
- **Streaming**: HLS.js, Video.js مع محرك بروكبسي سيادي لجلب الصوت من يوتيوب.

---

## 🖥 الشاشات والوظائف (Screens & Modules)

### 1. لوحة التحكم (Dashboard View)
*   **الوظيفة**: قلب النظام والعرض الشامل لكافة البيانات الحيوية.
*   **الميزات**:
    *   **Moon Widget**: يعرض طور القمر الحالي، التاريخ الهجري والميلادي، وحالة الطقس المباشرة.
    *   **Sovereign Clock**: ساعة SVG بصرية عالية الدقة مصممة للرؤية الليلية.
    *   **Prayer Timeline**: شريط زمني تفاعلي لمواقيت الصلاة مع نظام "الإقامة" الديناميكي.
    *   **Reminder Summary**: نظام تنبيهات ذكي يعرض التنازلي للمباريات والصلوات.
    *   **Wall Plate**: وضع العرض الفاخر (المخطوطات أو القمر) الذي يحول الشاشة إلى لوحة فنية.

### 2. مركز الوسائط (Media Hub)
*   **الوظيفة**: محرك استكشاف وتشغيل المحتوى البصري والصوتي.
*   **الميزات**:
    *   **Sovereign YouTube Engine**: بحث متقدم يدعم الروابط المباشرة، المجلدات، والبودكاست.
    *   **Podcast Hub**: نظام ذكي يكتشف قنوات البودكاست ويجلب أفاتاراتها من API يوتيوب مع إمكانية الحفظ السحابي.
    *   **Reciter Modal**: نافذة تخصيص تتيح اختيار السور، الأجزاء، أو حتى الصفحات (ص n) وتاريخ تسجيل التلاوة.
    *   **Adaptive Layout**: يتغير الهيكل آلياً (Sidebar للشاشات الكبيرة، عرض مدمج للجوال).

### 3. مركز الأذكار (Azkar View)
*   **الوظيفة**: رفيق الروح في الطريق.
*   **الميزات**:
    *   **عدادات تفاعلية**: أذكار الصباح والمساء مع خاصية النطق الصوتي (TTS).
    *   **أذكار سيادية**: إمكانية إضافة أذكار مخصصة وتخزينها سحابياً لتظهر في "الجزيرة العائمة".

### 4. مركز كووورة (Football Hub & HiHi2)
*   **الوظيفة**: رصد حي لكافة الفعاليات الرياضية العالمية.
*   **الميزات**:
    *   **Live Match Island**: جزيرة عائمة تظهر في كافة الصفحات لتتبع نتيجة المباراة المفضلة.
    *   **AI Summary**: استخدام Genkit لإنشاء ملخصات تحليلية مشوقة للمباريات بأسلوب رياضي.
    *   **Multi-Radar**: شاشة (HiHi2) تتيح تشغيل رادارين رياضيين في وقت واحد لمتابعة النتائج والأخبار.

### 5. مركز البث (IPTV Hub)
*   **الوظيفة**: تشغيل قنوات البث المباشر.
*   **الميزات**:
    *   **Proxy Streaming**: جلب القنوات عبر خوادم وسيطة لضمان الاستقرار.
    *   **Favorites Reorder**: إمكانية ترتيب القنوات المفضلة سحابياً عبر السحب والإفلات.

### 6. الإعدادات السيادية (Sovereign Settings)
*   **الوظيفة**: المعايرة الكاملة للنظام.
*   **الميزات**:
    *   **Button Mapping**: برمجة أي زر في الريموت لتنفيذ إجراء معين (نظام التسجيل المباشر).
    *   **Manuscript Studio**: استوديو لتصميم النصوص الإسلامية وتنسيقها وتحويلها إلى صور شفافة.
    *   **Cloud Sync**: التحكم الكامل في صناديق JSONBin (القراء، القنوات، التذكيرات).

## 🚀 الميزات الفريدة (Sovereign Core Features)

1.  **Remote Pointer Protocol**: نظام ملاحة ذكي بالجويستيك يتعرف على العناصر القابلة للتركيز (`focusable`) ويتحرك بينها بسلاسة الحرير.
2.  **Voice Command Hub**: محرك أوامر صوتية مدمج (اضغط 0 للتحدث) للانتقال بين الشاشات أو البحث.
3.  **Floating Islands**: نظام جزر تنبيهية (شبه نظام iOS) يظهر في أعلى الشاشة لإشعارك بموعد الصلاة، المباراة، أو انتهاء التذكير.
4.  **Auto-Click Sync**: محرك مزامنة آلي يقوم بتحديث البيانات السحابية في الخلفية كل بضع ثوانٍ لضمان التوافق بين الأجهزة.
5.  **External Popup Protocol**: إمكانية فتح أي فيديو أو بث في نافذة مستقلة (PiP) خارج المتصفح للعمل في الخلفية.

## 🛠 المكتبات والوظائف الأساسية (Functions & Libs)

*   **`useMediaStore` (Zustand)**: الوظيفة المركزية لإدارة الحالة، تحتوي على كافة منطق (التبديل، التشغيل، الحفظ، المزامنة).
*   **`SovereignIframe`**: مكون مخصص يتجاوز قيود التشغيل التلقائي (Autoplay) وكتم الصوت في المتصفحات.
*   **`fetchWithRotation`**: وظيفة ذكية لتدوير مفاتيح YouTube API لضمان عدم توقف البحث أبداً.
*   **`normalizeKey`**: محرك معالجة مفاتيح الريموت كنترول بكافة أنواعها (Android TV, Tizen, WebOS).
*   **`Genkit Flows`**: وظائف Server-side لمعالجة الذكاء الاصطناعي للاقتراحات والتحليل الرياضي.
